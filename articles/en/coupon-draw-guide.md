# Four Chances, One Coupon to Use

mygpt.work turns a normal coupon request into a user-controlled choice. Approval does not send repeated emails. One email contains the first random coupon and a secure entry to the draw page.

If the customer wants another result, they can actively draw three more times during the 30-minute activity window. That creates up to four visible candidates in one batch. The same email link can reopen the draw page while the activity remains valid, so leaving the page does not erase revealed results.

## The result can vary

A candidate may be a fixed CNY discount or a percentage discount. The result is random within the current activity configuration, and fixed-amount coupons follow their displayed plan scope.

## Only one candidate can win

The customer chooses which candidate to apply. The moment one is applied, the system locks it and ends the batch. Order creation checks the same rule again, and the remaining unused candidates are removed. This prevents simultaneous use and makes the final discount unambiguous.

One email can keep one unused draw batch for each plan. After the batch is used or expires, the customer can follow the current request rules again.
