# What Does “Codex Top-Up” Mean?

People often search for “Codex top-up” when they need more coding-agent usage. The answer depends on which product they are actually using.

## ChatGPT subscription

A ChatGPT plan controls product features and included usage inside ChatGPT. Codex is available through multiple ChatGPT plans, but the amount and limits can differ. See OpenAI's [Codex plan guidance](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan).

## Codex Credits

Credits are an additional usage balance in supported contexts. They are not a new monthly plan and do not change the account's subscription name.

## OpenAI API billing

API usage belongs to the developer platform, uses API keys, and has its own billing flow. A ChatGPT subscription is not API balance. The [OpenAI API quickstart](https://platform.openai.com/docs/quickstart) describes that separate workflow.

## Where mygpt.work fits

mygpt.work provides ChatGPT personal subscriptions for the customer's own account. It makes Go, Plus, Pro 5x, and Pro 20x easy to compare in CNY and supports Alipay or WeChat payment. It does not present those subscriptions as API credit.

Before ordering, check the Usage page in the customer's account and choose the plan that matches the actual Codex workload.
