很多人搜索“Codex 充值”，真正想解决的是 Codex 用量不够，或者想知道该升级哪一个 ChatGPT 套餐。Codex、Credits 和 API 看起来都与模型用量有关，但它们属于不同的产品与计费入口。

## Codex 通常随 ChatGPT 套餐提供

根据 OpenAI 当前说明，Codex 已包含在多种 ChatGPT 套餐中，不同套餐对应的使用量和限制可能不同。因此，用户口中的“Codex 充值”通常是为自己的 ChatGPT 账号选择或升级套餐，并不是购买一份完全独立的 Codex 会员。

mygpt.work 页面提供的是 ChatGPT 个人订阅套餐。选择前应查看账号内的 Usage 页面，并以 [OpenAI 的 Codex 套餐说明](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan)为准。

## Codex Credits 是什么

Credits 是按量余额。套餐内包含的用量先被消耗，用完后，受支持的功能才可能继续从 Credits 中扣除。是否可以购买、适用于哪些功能、当前费率是多少，都应以账号内 Usage 页面显示为准。

Credits 不等于新的月度订阅，也不能改变账号的套餐名称。关于重置卡、即时重置和 Credits 的差别，可阅读[重置卡与 Credits 使用说明](https://mygpt.work/blog/codex-reset-cards-and-credits)。

## OpenAI API 余额为什么不能通用

OpenAI API 面向开发者平台，通过 API key 调用模型，并在开发者平台独立计费。ChatGPT 个人订阅不会自动变成 API 余额，API 充值也不会自动升级 ChatGPT 套餐。

OpenAI 的[开发者快速入门](https://platform.openai.com/docs/quickstart)会要求创建 API key，并在开发者平台管理 API 账单，这与 ChatGPT 订阅页面是两套流程。

## 三者应该怎么选

| 你的需求 | 对应入口 |
| --- | --- |
| 在 ChatGPT 网页或客户端使用 Codex | 查看 ChatGPT 套餐与账号 Usage 页面 |
| 套餐内 Codex 用量用完后继续按量使用 | 查看账号是否支持购买 Credits |
| 在自己的程序中调用 OpenAI 模型 | 使用 OpenAI 开发者平台和 API 计费 |

如果你的目标是在本人 ChatGPT 账号上开通套餐，可以从[首页套餐区](https://mygpt.work/#plans)开始；如果主要是不清楚 Go、Plus 和 Pro 的差别，先阅读[ChatGPT 套餐选择指南](https://mygpt.work/blog/chatgpt-plan-guide)。
