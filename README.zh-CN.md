## 为什么选择 mygpt.work

### 1. 付款金额更清楚

- 套餐以人民币展示，付款前即可确认实际金额。
- 支持支付宝和微信付款，不要求海外信用卡。
- 订单创建后锁定金额，之后的汇率或页面调价不会改变该笔订单。

### 2. 本人账号订阅，不是共享账号

- 订阅作用于用户提交的本人 ChatGPT 账号。
- 不出售共享账号、成品账号，也不把 ChatGPT 订阅描述成 OpenAI API 余额。
- 套餐权益以 [ChatGPT 官方套餐页面](https://chatgpt.com/pricing/) 和用户账号内实际显示为准。

### 3. 处理快，进度还能随时查

- 确认付款后订单进入账号核验与订阅处理队列，预计 5～10 分钟完成；核验或排队可能延长处理时间。
- 付款状态与充值状态分开记录，过程更清楚。
- 原下单浏览器可直接查单；换浏览器或清除 Cookie 后，可用下单邮箱验证码获得 24 小时只读查询权限。

### 4. 优惠券不是简单发一张，而是给用户选择机会

- 申请通过后，邮件先发送第一张随机优惠券和抽卡入口。
- 30 分钟内可主动再抽 3 次，一批最多出现 4 张候选券。
- 优惠可能是固定金额，也可能是折扣。
- 最终只能应用一张；一旦应用，系统立即锁定所选券并结束本批活动，同批其余券自动清理。

详细规则见 [优惠券特色](./COUPONS.zh-CN.md)。

### 5. 邀请好友，双方都有奖励

完成付款的用户可获得专属邀请链接。受邀好友通过链接购买并完成付款后，邀请人与被邀请人各获得一张对应套餐的优惠券。不同套餐可以配置不同的固定金额或固定折扣。

### 6. 把隐私边界讲清楚

- 登录会话在浏览器内加密后提交，只用于当前订单的账号核验和订阅操作。
- 服务端会话密文与密钥最长保留 15 分钟。
- 不要求用户提供支付宝或微信支付密码，也不收集银行卡信息。
- 邮件中不包含登录会话；公开机器资料不包含邮箱、订单、券码或后台配置。

具体边界见 [隐私与安全](./PRIVACY-SECURITY.zh-CN.md)。
